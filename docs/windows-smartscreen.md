# Windows SmartScreen warning / Cảnh báo Windows SmartScreen

## vi

Khi anh/chị chạy bộ cài (và có thể cả lần mở app đầu tiên), Windows có thể hiện hộp **"Windows đã bảo vệ PC của bạn"** (tiếng Anh: "Windows protected your PC"). Đây là chuyện bình thường với bản cài này.

**Cách mở app:**
1. Bấm **Thông tin thêm** ("More info").
2. Bấm **Vẫn chạy** ("Run anyway").

Chỉ cần làm một lần cho mỗi bản cài.

**Vì sao có cảnh báo?** Zumi chưa được ký số (code signing). Windows hiện cảnh báo cho mọi app chưa ký hoặc còn ít người tải. Đây **không phải dấu hiệu có virus**. Chúng tôi sẽ xin chữ ký số khi có điều kiện.

**Kiểm tra anh/chị tải đúng nơi chính thức:**
- Chỉ tải từ trang tải chính thức do Zumia Space công bố.
- Nếu file đến từ chỗ khác (tin nhắn, link lạ), đừng chạy.



## en

When you run the installer (and possibly at the first launch), Windows may show **"Windows protected your PC"** (on a Vietnamese Windows: "Windows đã bảo vệ PC của bạn"). This is expected for this build.

**To open the app:**
1. Click **More info** ("Thông tin thêm").
2. Click **Run anyway** ("Vẫn chạy").

You only need to do this once per install.

**Why does this appear?** Zumi is not code-signed yet. Windows warns about every unsigned app, or one few people have downloaded. It is **not a sign of a virus**. We plan to apply for code signing when we can.

**Check you downloaded it from the official place:**
- Download only from the official download page published by Zumia Space.
- If the file came from somewhere else (a message, an unknown link), do not run it.
