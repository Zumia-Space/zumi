## vi
• Zumi 0.3.2: bản cập nhật gồm các thay đổi của 0.3.1 cùng các sửa lỗi dưới đây. Hiện có cho Windows; Mac và Linux làm sau.
• Mới: thẻ Bảng (Board) hiện các việc được ghim ở đầu bảng.
• Sửa: thẻ Bảng không còn chứa tên máy tính và đường dẫn thư mục nội bộ.
• Sửa: lần mở bằng --data-dir được nhớ trong file zumi-data-dir.txt cạnh file .exe, nên mở Zumi cách khác vẫn dùng đúng thư mục dữ liệu đó. Nếu thư mục đó không dùng được, Zumi ghi lại trong logs/data-dir.log và báo cho bạn một lần. Xoá file zumi-data-dir.txt để về thư mục mặc định.
• Sửa: mở tệp hoặc thư mục từ Zumi giờ tìm đúng trong thư mục dữ liệu bạn đã chọn khi mở ứng dụng.
• Vấn đề đã biết: xuất ghi chú chưa có hộp thoại chọn nơi lưu. Gỡ cài đặt để lại khoá HKCU\Software\zumia\Zumi trong registry. Lần mở đầu có thể chậm hơn trên máy dùng WebView2.
• Bản cài chưa ký số nên Windows SmartScreen có thể cảnh báo: chọn "Thông tin thêm" rồi "Vẫn chạy".

## en
• Zumi 0.3.2: an update that includes the 0.3.1 changes plus the fixes below. Windows for now; Mac and Linux come later.
• New: the Board tab shows pinned tasks at the top.
• Fixed: the Board tab no longer carries internal computer names or folder paths.
• Fixed: a --data-dir launch is remembered beside the exe (zumi-data-dir.txt), so starting Zumi any other way opens the same data folder. If that folder cannot be used, Zumi writes the reason to logs/data-dir.log and tells you once. Delete zumi-data-dir.txt to go back to the default folder.
• Fixed: opening a file or folder from Zumi now looks in the data folder you started the app with.
• Known issues: exporting notes has no save dialog yet. Uninstalling leaves the HKCU\Software\zumia\Zumi registry key behind. First start can be slower on PCs that use WebView2.
• The installer is not code-signed yet, so Windows SmartScreen may warn you: choose "More info", then "Run anyway".
